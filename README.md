# Курсовая работа: веб-приложение автосервиса

Учебный проект: сайт/веб-приложение автосервиса в стиле каталога (как “витрина”), где можно:
- зарегистрироваться и войти в аккаунт;
- просматривать каталог услуг и машин;
- оформить заявку/заказ (без реальных платежей, приближенно к реальности);
- написать в чат поддержки;
- переключать язык интерфейса (заготовка i18n).

## Стек
- Backend: **Django 6**
- База данных: **SQLite (по умолчанию)** или **PostgreSQL** (предпочтительно)
- Frontend: Django templates + **Tailwind CSS (CDN)** + небольшая логика на JS
- Чат поддержки: polling (AJAX) + хранение сообщений в БД

## Установка и запуск (локально)
1. Перейдите в папку `autosite`.
2. (Опционально) Активируйте виртуальное окружение:
   - `.\venv\Scripts\Activate.ps1` (PowerShell)
3. Примените миграции:
   - `python manage.py migrate`
4. Создайте администратора (для админки):
   - `python manage.py createsuperuser`
5. Запустите сервер:
   - `python manage.py runserver 127.0.0.1:8000`

После запуска откройте:
- Главная: `http://127.0.0.1:8000/`
- Админка: `http://127.0.0.1:8000/admin/`
- Чат поддержки: `http://127.0.0.1:8000/support/` (требуется вход)

## Настройка PostgreSQL
По умолчанию используется SQLite. Чтобы задействовать PostgreSQL, задайте переменные окружения:
- `POSTGRES_DB`
- `POSTGRES_USER`
- `POSTGRES_PASSWORD`
- `POSTGRES_HOST` (по умолчанию `127.0.0.1`)
- `POSTGRES_PORT` (по умолчанию `5432`)

Пример (PowerShell):
```powershell
$env:POSTGRES_DB="autoservice"
$env:POSTGRES_USER="postgres"
$env:POSTGRES_PASSWORD="password"
$env:POSTGRES_HOST="127.0.0.1"
```

Далее выполните `migrate` и запускайте проект как обычно.

## Архитектура и ключевые сущности
Модели:
- `accounts.CustomUser` — пользователи, роли
- `catalog.ServiceCategory`, `catalog.Service` — каталог услуг
- `catalog.CarCategory`, `catalog.Car` — каталог машин
- `orders.Order` — заявки/заказы (услуги и покупка авто)
- `support.Conversation`, `support.Message` — чат поддержки и сообщения

## Картинки машин (WebP)
В проекте изображения лежат локально в папке `autosite/cars/` и раздаются Django в режиме `DEBUG` по URL виду `/cars/...`.
В поле `Car.image_url` храните путь относительно `autosite/cars/` до файла вида `... 1.webp` — сайт автоматически подставит `2..5.webp` на основе имени.

## Безопасность (кратко)
Подробности см. в `docs/SECURITY.md`.

Ключевое:
- CSRF-защита для форм и отправки сообщений;
- XSS: экранирование текстов (Django templates autoescape);
- логин только для защищённых страниц/endpoint’ов;
- валидация входных данных (например, ограничения длины сообщений);
- мини-лимит на отправку сообщений в чате.
